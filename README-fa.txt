پیشونی | نسخه‌ی PWA آفلاین

۱. کل محتوای این پوشه را روی یک هاست HTTPS آپلود کنید (مثلاً GitHub Pages، Netlify، Cloudflare Pages یا هاست خودتان).
   فایل index.html باید در ریشه‌ی همان آدرس باشد. سرویس‌ورکر فقط روی HTTPS (یا localhost) کار می‌کند.
۲. آدرس را در Chrome اندروید باز کنید، دکمه‌ی «نصب روی گوشی» یا منوی ⋮ ← «افزودن به صفحه‌ی اصلی / نصب برنامه» را بزنید.
۳. بعد از اولین باز شدن، بازی کامل آفلاین اجرا می‌شود (فونت‌ها، آیکن‌ها و کد همه کش می‌شوند).

تست محلی:  python3 -m http.server 8080  و بعد  http://localhost:8080
به‌روزرسانی: فایل‌ها را عوض کنید و نام CACHE را در sw.js تغییر دهید تا نسخه‌ی جدید جایگزین شود.
